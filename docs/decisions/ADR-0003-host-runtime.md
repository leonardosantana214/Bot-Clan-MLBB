# ADR-0003 — Runtime do Host Android

Status: **Proposta / Pendente** (depende de PoC)

**Decisão provisória:** validar com PoC-1 em Termux (não é produto final); medir nodejs-mobile (PoC-2); manter motor externo (alternativa D) como contingência. Nenhuma UI do Host antes do resultado. Ver [viabilidade](../mobile/ANDROID_HOST_FEASIBILITY.md).
**Critério de revisão:** relatório de medições em aparelho real.
